# Contributing

Thank you for looking. These packages are maintained by a small team alongside [Otenos](https://otenos.com), so a few notes help us answer quickly.

- **Bugs:** open an issue with the smallest input that shows the problem and what you expected. A failing test is the best bug report.
- **Pull requests** are welcome. Keep one change per pull request, add a test, run `pnpm check`, and add a changeset with `pnpm changeset`.
- **New features:** open an issue first. Each package solves one problem we hit in production; a feature that widens its scope may fit better as a separate tool.
- **Security issues:** see [SECURITY.md](SECURITY.md); please do not open a public issue.

We review on a best-effort basis and cannot promise a timeline.
